# Psychophysical Dual-Task Experiment Framework

A PsychoPy implementation designed to quantify chromatic discrimination thresholds and categorization boundaries under concurrent cognitive load.

## Requirements
* Python 3.8+ (tested on Python 3.10)
* [PsychoPy](https://www.psychopy.org/)
* `numpy`, `scipy`, `pandas`

```bash
pip install psychopy numpy scipy pandas
